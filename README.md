## 📖 О проекте

Этот бот является фронтенд-интерфейсом для [AI Knowledge Base API](https://github.com/AlexeyDemidow/AI_knowledgebase). Пользователь может:

- загружать документы (файлы или по ссылке) в свою персональную базу знаний
- задавать вопросы по конкретному документу — бот найдёт релевантные части через **RAG** и ответит строго по тексту
- просто общаться с AI в режиме обычного чата
- управлять своими документами (просматривать список, удалять)

Каждый пользователь работает в изолированном диалоге — его документы и история не пересекаются с другими.

---

## ✨ Возможности

- 📄 **Загрузка документов** — отправьте файл напрямую в чат или укажите URL
- 🔍 **RAG-режим** — ответы строго по содержимому выбранного документа с указанием источника
- 💬 **Режим чата** — свободный диалог с AI с сохранением истории
- 📚 **Управление документами** — просмотр загруженных файлов, выбор документа для работы, удаление
- 🌐 **Поддержка двух языков** — автоматическое определение языка документа (RU/EN)

## 🚀 Установка и запуск

### Предварительные требования

Перед запуском бота необходимо развернуть бэкенд:  
👉 [AI_knowledgebase](https://github.com/AlexeyDemidow/AI_knowledgebase)

### Локальный запуск

```bash
# Клонировать репозиторий
git clone https://github.com/AlexeyDemidow/AI_knowledgebase_tg_bot.git
cd AI_knowledgebase_tg_bot

# Создать и активировать виртуальное окружение
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Установить зависимости
pip install -r requirements.txt

# Настроить переменные окружения
cp .env.example .env
# Заполнить .env своими значениями

# Запустить бота
python bot.py
```

## ⚙️ Переменные окружения

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=your_telegram_bot_token
ADMIN_ID=your_telegram_user_id
URL=http://localhost:8000
```

| Переменная | Описание |
|-----------|---------|
| `BOT_TOKEN` | Токен бота от [@BotFather](https://t.me/BotFather) |
| `ADMIN_ID` | Telegram ID администратора |
| `URL` | Базовый URL бэкенд API ([AI_knowledgebase](https://github.com/AlexeyDemidow/AI_knowledgebase)) |
